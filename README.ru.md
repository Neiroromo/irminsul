# Aaru

[English](README.md) · **Русский**

> Aaru — это форк [konkers/irminsul](https://github.com/konkers/irminsul), оригинального экспортёра данных Genshin Impact через перехват пакетов. Оригинал распространяется под лицензией MIT, файл лицензии сохранён в этом репозитории.

Программа (внутри по-прежнему Irminsul, файл `irminsul.exe`) читает сетевой трафик Genshin Impact (перехват пакетов, без сканирования экрана) и превращает его в полезные данные: экспорт для [Genshin Optimizer](https://frzyc.github.io/genshin-optimizer/) в формате GOOD, обзор персонажей и материалов, планировщик фарма и живую карту, которая знает, что вы уже собрали.

В игру ничего не внедряется, файлы игры не изменяются.

## Возможности

### Из оригинала

- Экспорт артефактов, оружия, материалов и персонажей в формате [GOOD](https://frzyc.github.io/genshin-optimizer/#/doc) в буфер обмена или в файл, с настройкой того, что экспортировать
- Экспорт достижений и трекер достижений

### Добавлено в этом форке

**Данные аккаунта**

- Вкладки «Персонажи» и «Материалы» с данными захваченного аккаунта, на русском или английском
- Персонажи и оружие, которых ещё нет во встроенных данных, подтягиваются из актуальных данных игры
- Отдельный профиль для каждого игрового аккаунта со свежим захватом, с переключением между аккаунтами
- Запуск игры через HoYoPlay так, чтобы Irminsul видел трафик, автозапуск вместе с Windows, режим трея и окно с прогрессом захвата
- Окно «что изменилось»: мора и предметы, полученные или потраченные во время игры
- Продолжение захвата после перезапуска программы без перезапуска игры; если ключ соединения найти не удалось, карта поверх игры сообщает об этом вместо неверных данных
- Фоновый лог, который всегда пишется и удаляется при закрытии программы, если не нажать кнопку в Power Tools, чтобы сохранить его (так не воспроизводимую проблему всё равно можно разобрать)

**Планировщик**

- Выбор персонажей и оружия, целевых уровней и талантов, итоговый список того, что нужно нафармить, и сколько уже есть
- Подземелья с днями открытия, материалами и артефактами, которые они дают, и разовыми наградами за первое прохождение

**Интерактивная карта**

- Официальная интерактивная карта: все регионы и подземные локации, этажи, фильтры по каждому виду меток
- Состояние «собрано» берётся из самой игры для окулей, сундуков, загадок, сили, мировых заданий и испытаний, плюс ручные отметки для того, о чём игра не сообщает
- Ваша позиция и этаж, а также оверлей карты, который можно показать поверх игры по горячей клавише
- **Показать на карте** для любого материала, из вкладки «Материалы», планировщика и контекстного меню: растения, руды, враги, лей-линии и подземелья, откуда он берётся
- Недельные боссы, старые разовые подземелья и подземелья артефактов, награды показываются по клику
- Боссы за смолу помечены как такие вместо времени возрождения
- **Отметки поверх большой карты самой игры**: когда в игре открыта большая карта, выбранные отметки рисуются поверх неё на своих местах, следуют за ней при сдвиге и масштабе и показываются только после того, как карта опознана
- **Противники**: игра присылает живых противников рядом, поэтому список тех, чьи виды выбраны, показывается справа поверх игры с расстоянием, разницей высот и стрелкой, куда идти (список можно перетаскивать); когда убит последний противник лагеря, его метка отмечается выполненной на сутки

**Планировщик маршрута**

- Выберите материалы или виды меток для фарма, при желании с учётом точек телепорта, и сгенерируйте маршрут по всем им
- Маршрут разбит на пронумерованные этапы (телепорт, сбор, следующий этап), нарисован цветными линиями со стрелками, читаемыми при любом масштабе, а переходы между этапами показаны пунктиром
- Прохождение по шагам кнопками «Начать», «Следующий шаг» и «Назад», карта следует за текущим этапом
- Близкие точки собираются вместе, прежде чем маршрут идёт дальше, и учитываются этажи подземных локаций
- Материал можно добавить в маршрут из его контекстного меню; то, что нельзя нафармить в открытом мире, не предлагается

**Лента событий**

- Текущие и предстоящие события по официальным объявлениям игры, версии игры и периодические сбросы, такие как Витая Бездна и Театр воображения

## Требования

- Windows 10 (версия 1809 или новее) или Windows 11, 64-бит
- Права администратора. Irminsul запрашивает их при запуске, они нужны, чтобы наблюдать за трафиком игры
- [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe). Он нужен программе, и на большинстве систем уже установлен. [Официальная страница](https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist)
- Доступ в интернет. Тайлы карты, иконки, данные меток и актуальные данные игры скачиваются и кэшируются
- По желанию: [Npcap](https://npcap.com/#download), только если запускать программу с `--capture-backend pcap`

Программа состоит из одного файла `irminsul.exe`: все остальные данные встроены, а профили и кэш хранятся в `%APPDATA%\Irminsul`.

## Начало работы

1. Скачайте `irminsul.exe` из [последнего релиза](https://github.com/Neiroromo/Aaru/releases/latest).
2. Запустите его и подтвердите запрос прав администратора.
3. Запустите захват пакетов, затем запустите игру и войдите в дверь (или воспользуйтесь встроенным запуском игры). Irminsul должен работать до того, как игра выполнит вход на сервер.
4. Когда появятся галочки, вкладки заполнятся вашими данными.

## Параметры командной строки

- `--capture-backend <pktmon|pcap>` (`-b`): `pktmon` используется по умолчанию и не требует драйвера; `pcap` требует Npcap и сборки с функцией `pcap`
- `--no-admin`: не показывать автоматический запрос прав администратора

## Сборка

```
cargo build --release
```

Для сборки нужен доступ в интернет, потому что при ней скачиваются некоторые данные игры.
